# Exploring Datasets

You can now use the user interface to browse and inspect data objects from the datasets that you have access to. First, navigate to the **DRS** page and select a dataset from the dropdown menu.

<CenteredImage src={DrsSelectDatasetImage} alt="dataset selection dropdown" maxWidth="60%" />

After selecting a dataset, a table will load displaying DRS Object IDs for **DRS Objects** within that dataset. You can paginate through the list of results as well as adjust the number of results per page.

**Note:** DRS stands for **Data Repository Service**, which is a GA4GH API specification for obtaining data objects. You can think of a DRS Object as containing basic metadata about a file (name, size, checksum, etc), as well as access methods to obtaining the raw file content.

Each row represents a **DRS Object Manifest**, which is a logical grouping of multiple related files (for example, a BAM file and its associated index, or all files derived from the same individual).

<CenteredImage src={DrsTableImage} alt="DRS Object table" maxWidth="85%" />

Click on a DRS Object ID to inspect its metadata. You can even click the **Download** button to download the raw data to your local machine!

<CenteredImage src={SingleDrsObjectImage} alt="Inspect single DRS Object" maxWidth="85%" />

**Note:** DRS Object Manifests cannot be inspected or downloaded, as they only contain references to the individual DRS Objects within the group.

You may be wondering, _"How can I access these data objects if I haven't supplied my passport token?"_ In the user interface, your passport token is minted and provided to the data access API automatically!
